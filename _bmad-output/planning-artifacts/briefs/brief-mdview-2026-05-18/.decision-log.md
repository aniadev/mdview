# Decision Log — mdview Product Brief

## Session: 2026-05-18

### D001 — Stack: Tauri (cross-platform Mac + Windows)
- Decision: Tauri thay vì Electron
- Reason: User chọn sẵn. Tauri nhẹ hơn, bundle nhỏ hơn, phù hợp side project public release.

### D002 — Editor mode: Split-pane
- Decision: Split-pane (raw markdown trái / rendered preview phải)
- Reason: User explicitly chọn. Không WYSIWYG, không raw-only.

### D003 — File tree: Full folder tree + dim non-.md folders
- Decision: Hiển thị toàn bộ folder structure; giảm opacity folder không chứa .md
- Reason: Unique UX insight từ user. Khác Obsidian (chỉ hiện .md) — giữ context folder dự án mà vẫn focus vào markdown.

### D004 — Out of scope v1
- Export PDF/HTML: out
- Git integration: out
- Custom themes: out
- Reason: Side project, v1 scope tight.

### D005 — Target: Public release
- Decision: Build để release cho người khác dùng, không chỉ cá nhân
- Implication: Cần installer, UX polish, cross-platform testing thực sự.

### D006 — Search in files
- Decision: Cmd+P / Ctrl+P file quick-open (theo tên) IN scope v1
- Full-text search trong nội dung file: OUT scope v1
- Reason: User confirmed — file navigation search như VSCode, không phải grep-style search
