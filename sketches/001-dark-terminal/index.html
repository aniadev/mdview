// features

Everything around the text,
out of the way

An editor first, a workbench second. The tree, the preview and the terminal exist to serve one file at a time.

🗂️

Smart file tree

Folders without any .md inside are dimmed automatically. Your notes surface, node_modules disappears.

auto-dimming
👁️

Live GFM preview

Split-pane editor ↔ preview with drift-free heading-segment scroll sync. Checklists are clickable in both panes.

markdown-it
🧮

Math + diagrams

KaTeX inline and block math, plus fenced ```mermaid blocks that lazy-load only when needed.

KaTeX · Mermaid
💻

Integrated terminal

A real PTY panel with multi-session tabs. Sessions survive panel hide/show — your shell state stays alive.

xterm.js + PTY
🔍

Command Palette

Cmd+P fuzzy file search with recents first. Prefix # to search headings across the whole workspace.

fuzzy · Fuse.js
📚

Workspace search

Cmd+Shift+F full-text search over every .md, powered by a multi-threaded Rust backend with highlighted snippets.

Rust core
🔗

Wikilinks

Type [[ for fuzzy autocomplete across all files. Click any relative link in preview to open it as a new tab.

[[]] autocomplete
📓

Daily notes

Alt+D creates today's YYYY-MM-DD.md with a heading template, cursor at the last line, ready to type.

journaling
🕸️

Graph view

A D3 force-directed map of your workspace files and internal links — drag nodes, click to jump, pan & zoom.

new in v1.8
🤖 CLAUDE.md agent
🤖 AGENTS.md agent
🤖 .cursorrules agent

Built for the AI workflow

mdview recognizes agent instruction files — CLAUDE.md, AGENTS.md, .cursorrules — and gives them a distinct bot icon so you always know where your agent's instructions live. Backlinks show you every note that references the active file.

// v1.8.0

See your notes the way your brain does

The new D3 force-directed graph view renders every markdown file and internal link as a living network. Zoom, pan, drag nodes — click any node to open the file and expand it in the explorer.

  • Interactive force simulation, zero config
  • Sidebar tab + full editor-pane tab view
  • Backlinks panel lists every note pointing at the active file
