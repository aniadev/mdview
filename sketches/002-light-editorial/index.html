The philosophy

Dim the noise, keep the signal

Every design decision in mdview answers one question: does it make the next sentence easier to write?

01

The tree knows what matters

Folders with no markdown inside are dimmed, not hidden. Your notes surface against the project's real structure — no config, no filters to maintain.

// folders without .md descendants fade automatically
02

A preview that follows your eyes

Source left, rendered right. Scroll either pane and the other follows — a heading-segment algorithm keeps them aligned on even the messiest files.

// drift-free bidirectional scroll sync
03

Math, diagrams, and checklists that work

KaTeX math, Mermaid diagrams, interactive checklists. Click a box in the preview and the source updates — undo still works.

// markdown-it · KaTeX · Mermaid · task lists
04

One keystroke to today's note

Alt+D creates or opens YYYY-MM-DD.md, drops in a heading template, and parks the cursor on the last line. Three seconds from thought to keystroke.

// daily notes · configurable directory
05

Made for the files your agents read

CLAUDE.md, AGENTS.md, .cursorrules — recognized, given a bot icon, and wired into backlinks so you always know what your agent is reading.

// AI agent file recognition · backlinks
06

Open the folder, pick up where you left off

Recent workspaces, multi-root .code-workspace support, and a tree that remembers exactly what you had expanded.

// workspace persistence · multi-root
