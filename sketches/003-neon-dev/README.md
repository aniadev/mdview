# Variant: Neon Dev (C)

## Design stance

Maximum energy — a dark gradient-mesh background with drifting light orbs, glassmorphism cards, a scrolling capability marquee, and a "terminal demo" hero that reads like a CLI session. Built to stop the scroll.

## Key choices

- **Layout:** centered hero with full-width terminal mock, marquee strip, bento grid (8 cards incl. wide/tall), graph section, OS download cards
- **Typography:** Space Grotesk (geometric, modern dev-tool feel) + JetBrains Mono; gradient text on the headline
- **Color:** deep `#07080c` base, neon triad — cyan `#38e1ff`, blue `#4d9fff`, purple `#8b5cf6`, green `#34d399`; brand blue `#0078d4` upgraded to a brighter, more vivid family
- **Interaction:** marquee pauses on hover, bento cards lift + glow, animated dashed graph edges, pulse badge
- **Animation:** orbs drifting, marquee scroll, dash drift, hover glow — continuous gentle motion throughout

## Trade-offs

- Strong at: attention, modern dev-tool credibility (Linear/Vercel/Resend register), hero demo of the terminal feature
- Weak at: calm/writing audience; gradient noise can tire over a long scroll; slightly generic "AI startup" look if overdone

## Best for

A launch moment where grabbing attention matters more than conveying calm — ProductHunt, social sharing, a "look what this can do" statement.
